# 🤖 Enhanced Q&A Chatbot with OpenAI & LangChain

An AI-powered Q&A chatbot built using **OpenAI, LangChain, and Streamlit**. The application provides a simple interactive interface where users can ask questions and receive intelligent, context-aware responses from an OpenAI language model.

## ✨ Features

* 🤖 AI-powered question answering
* 🔗 LangChain-based LLM integration
* 💬 Interactive Streamlit interface
* 🎛️ Adjustable response temperature
* 📝 Configurable maximum response tokens
* 🧠 Support for multiple OpenAI models
* 🔐 Secure API key handling
* 📊 Optional LangSmith integration for tracing and monitoring

## 🛠️ Tech Stack

* **Python**
* **Streamlit**
* **LangChain**
* **LangChain OpenAI**
* **OpenAI API**
* **LangSmith**

## 🔄 Application Workflow

```text
User Question
      ↓
Streamlit Interface
      ↓
LangChain Prompt Template
      ↓
OpenAI Chat Model
      ↓
Output Parser
      ↓
AI Generated Response
```

## 🎯 Project Objective

The goal of this project is to demonstrate how **Large Language Models can be integrated into a practical AI application using LangChain**, while providing users with control over model behavior through configurable parameters.

## 💡 Key Concepts Demonstrated

* Large Language Model integration
* Prompt engineering
* LangChain chains
* Output parsing
* OpenAI API integration
* Streamlit application development
* LLM parameter tuning
* LangSmith observability
